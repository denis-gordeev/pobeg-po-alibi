# Побег по алиби

Абсурдный планировщик тактического исчезновения на живых данных [Tutu.ru MCP](https://mcp.tutu.ru/mcp).

Пользователь задаёт город отправления, дату, бюджет, причину побега и при желании собственный черновик алиби. Приложение проверяет реальные варианты транспорта, выбирает неожиданное направление, показывает маршрут на карте, составляет небольшой путеводитель и выдаёт пять вариантов алиби.

## Возможности

- поиск поездов, самолётов, автобусов и электричек через официальный Tutu.ru MCP;
- выбор необычного направления из каталога примерно 30 российских городов;
- описание атмосферы места и три идеи, что посмотреть;
- интерактивная карта маршрута на Leaflet и OpenStreetMap;
- пользовательский текст как основа для алиби;
- пять разных алиби за один запрос через LLM;
- четыре одновременных профиля маршрута: экономный, сбалансированный, дальний и «освоить бюджет»;
- фильтры по самолёту, поезду, автобусу и максимальному времени в пути;
- переключение между профилями с обновлением алиби без повторного поиска билетов;
- источник и время получения цены у каждого найденного варианта;
- отдельные кнопки копирования каждого варианта;
- локальная история четырёх последних операций на шесть часов с восстановлением, точечным удалением и синхронизацией между вкладками;
- явно обозначенный резервный режим при недоступности MCP или LLM;
- публичное контейнерное развёртывание в Yandex Cloud Serverless Containers.

Приложение не бронирует и не оплачивает билеты. Оно показывает найденный вариант и ведёт пользователя на страницу Tutu.ru для самостоятельного оформления.

## Локальный запуск

Потребуется Node.js 22 или новее.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Откройте `http://localhost:3000`.

Для LLM-генерации укажите в `.env.local` серверный ключ OpenRouter:

```dotenv
OPENROUTER_API_KEY=your-openrouter-key
OPENROUTER_MODEL=deepseek/deepseek-v4-flash-0731
```

Секрет используется только в серверном API и не попадает в браузер. Если провайдер недоступен, приложение возвращает пять резервных вариантов и помечает их как «Резервный штаб».

## Архитектура

- `app/page.tsx` — интерактивный интерфейс операции;
- `app/api/escape/route.ts` — выбор направления, вызов Tutu MCP и сборка результата;
- `app/api/alibis/route.ts` — обновление алиби для уже найденного альтернативного маршрута;
- `app/api/llm-relay/route.ts` — защищённый серверный relay для LLM;
- `app/RouteMap.tsx` — карта маршрута Leaflet/OpenStreetMap;
- `lib/alibis.ts` — единая генерация и резервные шаблоны алиби;
- `lib/planning.ts` — бюджетный скоринг и подбор четырёх неповторяющихся профилей;
- `lib/destinations.ts` — каталог городов, координат, описаний и достопримечательностей;
- `deploy/yandex-cloud.sh` — повторяемое развёртывание контейнера в Yandex Cloud;
- `Dockerfile` — production-образ приложения.

## Проверка

```bash
npm test
npm run lint
```

Тесты проверяют серверный рендеринг, базовую валидацию API и фильтров, ограничение длины пользовательского черновика, контракт четырёх профилей и обновление алиби без обращения к Tutu.

## План развития

Уже сделано: бюджетный скоринг маршрутов, семь быстрых лимитов бюджета, серверный LRU-кэш предложений Tutu, объяснение выбора, фильтры транспорта и длительности, четыре одновременных профиля и переключение между ними без повторного поиска билетов. У каждой цены показаны источник и время получения. Шестичасовой локальный архив версионирован, поддерживает восстановление и точечное удаление операций, очищает просроченные данные и синхронизируется между вкладками.

Ближайшие шаги: явный порог устаревания с обновлением цены, программа на 24/48/72 часа, телеметрия внешних запросов и автоматический E2E-контур. Актуальный подробный чек-лист ведётся в [`ROADMAP.md`](./ROADMAP.md).

## Развёртывание в Yandex Cloud

После настройки профиля `yc`, Docker и серверных переменных выполните:

```bash
./deploy/yandex-cloud.sh
```

Скрипт создаёт Container Registry, runtime service account с минимальным доступом к образу, выпускает ревизию Serverless Container и разрешает публичный вызов приложения.

Сделано как эксперимент для хакатона Tutu MCP.
