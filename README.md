# Побег по алиби

Абсурдный планировщик тактического исчезновения на живых данных [Tutu.ru MCP](https://mcp.tutu.ru/mcp).

Пользователь указывает город, дату, бюджет и причину побега. Приложение выбирает неожиданное направление, ищет реальный билет среди поездов, самолётов, автобусов и электричек и составляет официально звучащее алиби.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Как устроено

- `app/page.tsx` — интерактивный интерфейс операции.
- `app/api/escape/route.ts` — серверный вызов `search_multitransport` через Streamable HTTP MCP.
- При временной недоступности MCP включается явно помеченный учебный режим, чтобы интерфейс оставался демонстрируемым.

Приложение не бронирует и не оплачивает билеты. Оно показывает точную ссылку Tutu.ru, которую открывает сам пользователь.
