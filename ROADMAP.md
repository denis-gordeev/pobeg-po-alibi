# План развития «Побега по алиби»

## Сейчас

- [x] Бюджетный скоринг: цена, дальность и вид транспорта вместо выбора самого дешёвого билета.
- [x] Семь быстрых потолков бюджета: 7К, 20К, 50К, 100К, 250К, 500К и 1М ₽.
- [x] LRU-кэш четырёх последних наборов предложений Tutu на 15 минут.
- [x] Объяснимый выбор: профиль операции, расстояние и доля использованного бюджета.
- [x] Четыре одновременных профиля маршрута: экономный, сбалансированный, дальний и «освоить бюджет».
- [x] Переключение профиля обновляет билет, карту, мини-гид и алиби без повторного вызова Tutu MCP.
- [x] У каждого профиля показаны источник цены и время получения набора предложений.
- [x] Локальный архив версионирован, синхронизируется между вкладками и поддерживает удаление одной операции.
- [x] Dev-сервер использует поддерживаемую Workers compatibility date и снова запускается локально.

Четыре профиля строятся из одного набора ответов Tutu без дополнительных билетных запросов. При выборе другого профиля отдельный API обновляет только пять алиби, а найденные цена, билет, карта и мини-гид переиспользуются. Алгоритм старается не повторять города; при недостаточном живом ответе интерфейс получает полный учебный набор. Панель истории сохраняет результат только в текущем браузере, автоматически удаляет его через шесть часов и восстанавливает вводные вместе с полной карточкой маршрута без сетевого запроса.
