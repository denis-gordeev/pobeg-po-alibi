# План развития «Побега по алиби»

## Сейчас

- [x] Бюджетный скоринг: цена, дальность и вид транспорта вместо выбора самого дешёвого билета.
- [x] Семь быстрых потолков бюджета: 7К, 20К, 50К, 100К, 250К, 500К и 1М ₽.
- [x] LRU-кэш четырёх последних наборов предложений Tutu на 15 минут.
- [x] Объяснимый выбор: профиль операции, расстояние и доля использованного бюджета.

## Следующий релиз

- [ ] Показывать четыре альтернативных маршрута одновременно: экономный, сбалансированный, дальний и «освоить бюджет».
- [ ] Перегенерировать алиби при переключении на альтернативный город без повторного поиска билетов.
- [ ] Добавить фильтры по самолёту, поезду, автобусу и максимальному времени в пути.
- [x] Сохранять последние четыре полных результата локально в браузере на шесть часов.
- [x] Добавить отдельную панель истории и восстанавливать сохранённые операции одним кликом.

## После этого

- [ ] Строить программу на 24/48/72 часа с достопримечательностями из мини-гида.
- [ ] Генерировать карточку маршрута для Telegram и сторис без раскрытия секретного токена.
- [ ] Добавить наблюдаемость: время Tutu, время LLM, доля кэш-хитов и причины fallback.
- [ ] Расширить географию и учитывать сезонность, ночные пересадки и часовые пояса.
- [ ] Добавить контрактные тесты для ответов Tutu MCP и OpenRouter.
- [ ] Добавить удаление одной операции из локальной истории без полной очистки архива.
- [ ] Добавить управление клавиатурой и проверку контрастности для всех интерактивных состояний.
- [ ] Версионировать формат локального кэша и безопасно мигрировать сохранённые результаты.

Панель истории завершает первый пользовательский цикл: результат сохраняется только в текущем браузере, автоматически истекает через шесть часов и восстанавливает вводные вместе с полной карточкой маршрута без сетевого запроса.
